# Personal Portfolio Website

A modern, responsive personal portfolio website designed to showcase my **skills, projects, education, certifications, and professional journey** in a clean and interactive way.

The portfolio serves as a central place to learn more about my technical background, explore my projects, and connect with me professionally.

### ✨ Features

* Responsive and modern UI
  
* About Me section
  
* Skills and technical expertise
  
* Project showcase with descriptions
  
* Education and certifications
  
* Contact section
  
* Social media and professional profile links
  
* Mobile-friendly design
  
* Smooth navigation and interactive elements

### 🛠️ Technologies Used

* HTML5
  
* CSS3
  
* JavaScript
  
* Responsive Web Design
  
* Git & GitHub

### 🎯 Purpose

This project was built to create a professional online presence and demonstrate my **web development, programming, problem-solving, and project-building skills** to recruiters, companies, and potential collaborators.
